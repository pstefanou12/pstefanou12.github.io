## Citing delphi.ai

If you use delphi.ai in your work, please cite it:

```bibtex
@software{stefanou_delphi,
  author  = {Stefanou, Patroklos},
  title   = {delphi: statistical estimation from truncated samples},
  url     = {https://github.com/pstefanou12/delphi.ai},
  version = {0.2.1.9},
  year    = {2026},
}
```
