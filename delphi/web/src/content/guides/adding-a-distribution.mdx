1. **Write the family class** in `delphi/exponential_family/`, and check that
   $\langle T(x), \theta \rangle + \log h(x) - \log p_\theta(x)$ is constant
   across samples.
2. **Write the truncated model.** If the untruncated MLE has a closed form,
   `_calc_emp_model` returns it. If not, it returns a rough start and the
   family's config enables the warm start
   (`WarmStartedExponentialFamilyDistributionConfig`), which refines that
   start to the untruncated MLE.
3. **Test it** with `helpers.assert_family_recovers` and
   `helpers.assert_family_distinguishes`, as the existing
   `truncated_*_test.py` modules do.

## Documenting it

Add the model to this site in two places:

1. `MODELS` in `delphi/scripts/extract_api.py` (in the site repo), then
   regenerate the API with `npm run docs:api`.
2. An entry in `SECTIONS` in `delphi/web/src/content/registry.ts`. The page
   then exists, built from the API. Optional prose and math go in
   `delphi/web/src/content/algorithms/<slug>.mdx`.

See [Models](/models) for the classes a family builds on.
