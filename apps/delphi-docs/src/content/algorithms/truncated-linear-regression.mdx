## Model

A linear model $y = w^\top x + b + \varepsilon$, $\varepsilon \sim \mathcal{N}(0, \sigma^2)$,
observed only where `phi(y)` admits the response. Least squares on such a
sample is biased toward the set. The variant follows the arguments:

| you pass | fits | paper |
|---|---|---|
| `noise_var` | $w, b$ with $\sigma^2$ known | Daskalakis et al. (2019) |
| `noise_var=None` | $w, b$ and $\sigma^2$, in the natural parameters $(w / \sigma^2, 1 / \sigma^2)$ | Daskalakis, Stefanou, Yao, Zampetakis (2021) |
| `dependent=True` | a linear dynamical system $x_{t+1} = A x_t + b + w_t$ from one trajectory | |

## Example

```python
import torch as ch

from delphi.stats.truncated import truncated_linear_regression

X = ch.randn(20000, 10)
y = X @ ch.ones(10, 1) + 0.5 + ch.randn(20000, 1)


def phi(z):
    return z > 4.0


kept = phi(y).flatten()
model = truncated_linear_regression.TruncatedLinearRegression(
    phi, kept.float().mean().item(), noise_var=1.0
)
model.fit(X[kept], y[kept])
model.coef_, model.intercept_
intervals = model.confidence_intervals(level=0.95)
intervals.coef.lower, intervals.coef.upper
print(model.summary())
```

## Arguments in practice

- **`phi` sees the response**, shaped `(n, m, 1)`, and returns a mask or a
  survival probability.
- **`alpha`** sets the projection radius $r^* = 4 \log(2 / \alpha) + 7$, unless
  the `radius` hyperparameter is given. Pass `None` when it is unknown: the
  radius then grows by `rate` each phase until the projection stops binding.
- **`noise_var=None`** learns the noise variance with the weight; read it
  from `variance_` (and `avg_`, `ema_`, `final_`, `best_variance_`). There
  `alpha` sets the projection set's $1 / \alpha$ instead, 1 when it is `None`.
- **`sampler`** estimates $P(z \in S)$ and the conditional moments for the
  loss; rejection sampling by default.

## Confidence intervals

`model.confidence_intervals(level=0.95)` returns Wald intervals as a
`ConfidenceIntervals`, whose `coef`, `intercept` (None without one) and
`variance` (None when `noise_var` is given) each hold `lower` and `upper`
bounds shaped as `coef_`, `intercept_` and `variance_`, on the scale of the
data passed to `fit`. `estimate` picks the iterate, a `constants.Estimator`
(`"avg"` by default).

`model.covariance()` is their asymptotic covariance, the inverse Fisher
information of the sample at the estimate: the truncated NLL's Hessian in the
weight for a known variance, and in the natural parameters
$(w / \sigma^2, 1 / \sigma^2)$, carried to $(w, \sigma^2)$ by the delta method,
for a learned one. `summary()` lists the 95% intervals. Dependent data has
none.

## Dependent data

`dependent=True` learns a linear dynamical system $x_{t+1} = A x_t + b + w_t$
from one trajectory observed only where `phi` admits the state. Pass the pairs
$(x_t, x_{t+1})$ with both states observed, in temporal order, as the rows of
`X` and `y`; the noise covariance as `noise_var`; and as `alpha` a lower bound
on the chance that an observed state's successor is observed.
`fit_intercept=False` fits a system without the drift $b$. The leading
`warm_start_fraction` of the pairs, a quarter by default, warms up the fit,
and the descent takes the rest once, in order. `coef_` estimates $A$ and
`intercept_` $b$.
